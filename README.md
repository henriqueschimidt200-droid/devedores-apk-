# Devedores 4.4

Aplicativo Android nativo para controle de clientes, empréstimos, parcelas, documentos, imagens, calendários e alarmes.

## Fotos dos clientes
- Foto de perfil do cliente.
- Galeria com várias imagens por cliente.
- Seleção de uma ou várias fotos de uma vez.
- Imagens copiadas para o armazenamento interno do app, dentro da pasta do cliente.
- Acesso à galeria mesmo sem internet.
- Botão destacado “Adicionar imagens” na ficha do cliente.

## Build
Use o workflow em `.github/workflows/android.yml` para gerar o APK pelo GitHub Actions.
